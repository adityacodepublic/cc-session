# claude-code-session-manage

list, resume, delete or start Claude Code sessions in the current folder

```
npm i -g @gitcodepublic/cc-session
cd your-project
ccs
```

| Key | Action |
|---|---|
| ↑ ↓ Home End | move |
| Enter | resume the session |
| n | start a new session |
| d, d | delete the session (press d twice) |
| q / Esc | quit |
